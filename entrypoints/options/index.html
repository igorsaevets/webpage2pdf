⚙️ webpage2pdf — Настройки

Бумага и куда сохранять PDF. Синхронизируется через Chrome Sync если включён.

Формат бумаги

Масштаб (paperWidth-0.8)*96/1920 чтобы 1920px влез в печатную область. Применяется сразу.

Куда сохранять

Например webpage2pdf → Downloads/webpage2pdf/файл.pdf. Оставь пустым — в корень Загрузок.

Chrome не умеет писать за пределы Загрузок напрямую. Для этого ставится маленький хост native-host/ (.exe + реестр). Без хоста — упадёт в Загрузки с предупреждением. Инструкция: native-host/README.md и install_host.bat.

⚠️ Native Host не установлен — пока будет сохранять в Загрузки. Запусти native-host/install_host.bat от имени пользователя и перезапусти Chrome.

Имя файла

Теперь: <url-base>-<дата>.pdf — например biznespark.by-2026-09-01.pdf, krokit.org-courses-product-2026-09-01.pdf. Запрещённые символы <>:"/\|?* заменяются на _.
